# Japanese Learning Resources

This is a list of resources for learning Japanese that I have used (or at least
  heard of) to some extent.
There are of course many more, but this is just about everything I've come
  across since I started my foray into learning Japanese.

## Dictionaries

The main dictionary I use is [Takoboto][takoboto].
It has mobile apps and a good web interface, it lets you input whole sentences
  and will break them apart, and it shows the stroke order for every kanji in a
  word (if you're trying to learn to write, that's extremely helpful).
